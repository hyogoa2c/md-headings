1. INTRODUCTION                                          *md-headings-intro*

md-headings.nvim is a modern Neovim plugin for hierarchical markdown
heading numbering. It provides commands to automatically number markdown
headings in a hierarchical format (1., 1.1, 1.1.1, etc.).

Features:
  • Hierarchical numbering (1., 1.1, 1.1.1)
  • Automatically removes existing numbers before renumbering
  • Configurable separator and formatting options
  • Respects markdown code blocks
  • Written in pure Lua for modern Neovim

2. INSTALLATION                                  *md-headings-installation*

Using lazy.nvim: >lua
    {
      "hyogoa2c/md-headings",
      ft = "markdown",
      config = function()
        require("md-headings").setup()
      end,
    }
<

      ft = "markdown",

        require("md-headings").setup()
      end
    }
<

3. USAGE                                                  *md-headings-usage*

Basic usage:
1. Open a markdown file
2. Run |:MarkdownNumberHeadings| to number all headings
3. Run |:MarkdownRemoveNumbers| to remove all numbers

The plugin will automatically detect ATX-style headings (# ## ###) and
number them hierarchically based on their level.

==============================================================================
4. COMMANDS                                            *md-headings-commands*

                                                   *:MarkdownNumberHeadings*
:MarkdownNumberHeadings
    Number all headings in the current buffer hierarchically.

    Example output:
        # 1. Introduction
        ## 1.1. Background
        ### 1.1.1. Details
        # 2. Main Content

                                                   *:MarkdownRemoveNumbers*
:MarkdownRemoveNumbers
    Remove all numbers from headings in the current buffer.
    This strips existing number prefixes while preserving heading content.

                                                   *:MarkdownToggleNumbers*
:MarkdownToggleNumbers
    Toggle the md-headings plugin on/off.
    When disabled, commands will not execute.

                                                   *:MarkdownTOC*
:MarkdownTOC
    Create a table of contents at the current cursor position.
    Generates a plain TOC without numbers, using markdown links to headings.

    Example output:
        ## Table of Contents

        - [Introduction](#introduction)
          - [Background](#background)
        - [Main Content](#main-content)

                                                   *:MarkdownTOCNumbered*
:MarkdownTOCNumbered
    Create a numbered table of contents at the current cursor position.
    Generates a TOC with hierarchical numbers matching the document headings.

    Example output:
        ## Table of Contents

        - [1. Introduction](#introduction)
          - [1.1. Background](#background)
        - [2. Main Content](#main-content)

5. CONFIGURATION                                        *md-headings-config*

Setup the plugin with custom configuration:
>lua
    require("md-headings").setup({
      enabled = true,
      separator = ".",
      add_space = true,
      start_level = 1,
      auto_number_on_save = false,
      skip_patterns = {},
      toc_add_header = true,
      toc_indent_size = 2,
    })
<

Configuration options:

enabled                                          *md-headings-config-enabled*
    Type: boolean
    Default: `true`

    Enable or disable the plugin. When disabled, commands will show
    a warning and not execute.

separator                                      *md-headings-config-separator*
    Type: string
    Default: `"."`

    Number separator to use. Valid values: "." or ")"

    Examples:
        "." -> # 1. Heading, ## 1.1. Subheading
        ")" -> # 1) Heading, ## 1.1) Subheading

add_space                                      *md-headings-config-add-space*
    Type: boolean
    Default: `true`

    Add a space between the number and heading text.

    Examples:
        true  -> # 1. Heading
        false -> # 1.Heading

start_level                                  *md-headings-config-start-level*
    Type: number
    Default: `1`
    Range: 1-6

    Start numbering from this heading level. Set to 2 to skip H1 headings.

    Examples:
        1 -> Number all headings (H1-H6)
        2 -> Skip H1, number H2-H6

auto_number_on_save              *md-headings-config-auto-number-on-save*
    Type: boolean
    Default: `false`

    Automatically renumber headings whenever the file is saved.
    Set to `true` to enable automatic renumbering on save.

skip_patterns                              *md-headings-config-skip-patterns*
    Type: table
    Default: `{}`

    List of Lua patterns to skip when numbering. Headings matching any
    pattern will not be numbered.

    Example:
>lua
        skip_patterns = {"^TOC", "^Table of Contents"}
<

toc_add_header                            *md-headings-config-toc-add-header*
    Type: boolean
    Default: `true`

    Add "## Table of Contents" header when generating TOC.
    Set to `false` to generate only the list without a header.

toc_indent_size                          *md-headings-config-toc-indent-size*
    Type: number
    Default: `2`

    Number of spaces per indentation level in table of contents.
    Controls how nested headings are indented.

    Example:
        2 -> Two spaces per level (default)
        4 -> Four spaces per level

6. FUNCTIONS                                        *md-headings-functions*

The following Lua functions are available via the main module:

require("md-headings").setup({opts})           *md-headings.setup()*
    Initialize the plugin with custom configuration.

    Parameters:
        {opts} (table) Configuration options

    Example:
>lua
        require("md-headings").setup({
          separator = ")",
          start_level = 2,
        })
<

require("md-headings").number_headings({bufnr})  *md-headings.number_headings()*
    Number all headings in the specified buffer.

    Parameters:
        {bufnr} (number, optional) Buffer number (defaults to current)

    Returns:
        (boolean) True if successful, false otherwise

require("md-headings").remove_numbers({bufnr})  *md-headings.remove_numbers()*
    Remove numbers from all headings in the specified buffer.

    Parameters:
        {bufnr} (number, optional) Buffer number (defaults to current)

    Returns:
        (boolean) True if successful, false otherwise

require("md-headings").toggle()                 *md-headings.toggle()*
    Toggle the plugin on/off.

    When toggled off, the plugin's commands will not execute.

require("md-headings").create_toc({bufnr})     *md-headings.create_toc()*
    Create a plain table of contents at cursor position.

    Parameters:
        {bufnr} (number, optional) Buffer number (defaults to current)

    Returns:
        (boolean) True if successful, false otherwise

    Generates TOC without numbers, using markdown links.

require("md-headings").create_toc_numbered({bufnr})  *md-headings.create_toc_numbered()*
    Create a numbered table of contents at cursor position.

    Parameters:
        {bufnr} (number, optional) Buffer number (defaults to current)

    Returns:
        (boolean) True if successful, false otherwise

    Generates TOC with hierarchical numbers matching document headings.

7. EXAMPLES                                          *md-headings-examples*

Example 1: Basic usage ~
>vim
    " Open a markdown file
    :edit document.md

    " Number all headings
    :MarkdownNumberHeadings
<

Example 2: Custom configuration ~
>lua
    require("md-headings").setup({
      separator = ")",           -- Use parentheses
      start_level = 2,           -- Skip H1 headings
    })
<

Example 3: Keybindings ~
>lua
    -- In your Neovim configuration
    vim.keymap.set("n", "<leader>mn", ":MarkdownNumberHeadings<CR>",
      { desc = "Number markdown headings" })
    vim.keymap.set("n", "<leader>mr", ":MarkdownRemoveNumbers<CR>",
      { desc = "Remove heading numbers" })
<

Example 4: Before and after ~

Before:
>markdown
    # Introduction
    ## Background
    ### Some Detail
    # Main Content
    ## Section A
<

After running :MarkdownNumberHeadings:
>markdown
    # 1. Introduction
    ## 1.1. Background
    ### 1.1.1. Some Detail
    # 2. Main Content
    ## 2.1. Section A
<
